# Supplementary Appendix A: source-verified parameter table

**MIDox implementation of the ALMaSS *Osmia bicornis* model**  
Christopher J. Topping, Elżbieta Ziółkowska and Xiaodong Duan

## A.1 Scope and authority

This appendix lists every configuration declaration in the verified post-calibration implementation. The compiled declaration defaults are the documented baseline. Configuration files can override these values for particular runs, but no separate calibrated configuration file defines the implementation described here. Calibration material is used only to identify the provenance of fitted values.

The inventory contains **100 unique configuration keys**. Fifteen declaration defaults differ from the Formal Model comparator and 85 are unchanged. Provenance and implementation status are separate: a fitted value may be unchanged from the Formal Model, while a declared setting may have no effect on current behaviour.

## A.2 Reconciliation summary

| Check | Result |
|:---|---:|
| Source declarations | 100 |
| Appendix rows | 100 |
| Formal Model differences | 15 |
| Unchanged from Formal Model | 85 |
| Active settings | 72 |
| Conditional settings | 20 |
| Settings with no effect on current behaviour | 8 |
| Parameters without a defensible range | 95 |

`Conditional` includes settings whose effect depends on an inactive-by-default mechanistic parasitoid pathway, the higher-level pesticide engine or a selected pesticide-response formulation. `No effect` is reserved for declarations that cannot change current model behaviour through the active code.

The eight no-effect keys are: `OSMIADENSITYDENPENDENTPOLLENREMOVALCONST`, `OSMIA_MALEMINTARGETPROVISIONMASS`, `OSMIA_MINCELLCONSTRUCTTIME`, `OSMIA_MINMALEMASS`, `OSMIA_NECTAR_THRESHOLDS`, `OSMIA_POLLEN_THRESHOLDS`, `OSMIA_PPP_KILL_RATE`, `OSMIA_PPP_RECOVERY_RATE`.
